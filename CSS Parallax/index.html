ESP32

ESP32 je populární řada nízkonákladových systémů na čipu (SoC) s nízkou spotřebou energie, kterou vyvinula společnost Espressif Systems. Je navržen jako výkonnější nástupce čipu ESP8266 a jeho hlavní předností je integrovaná Wi-Fi a duální Bluetooth (klasický i nízkoenergetický BLE). Srdcem většiny modulů ESP32 je dvoujádrový procesor Xtensa® 32-bit LX6, který může běžet na frekvenci až 240 MHz, doplněný o 520 KB paměti SRAM. Díky bohaté sadě periferií, která zahrnuje kapacitní dotykové senzory, ADC, DAC, UART, SPI, I2C a PWM, je ideální volbou pro projekty internetu věcí (IoT), nositelnou elektroniku a domácí automatizaci. Čip vyniká také v řízení spotřeby, kdy v režimu hlubokého spánku odebírá jen několik mikroampérů. Programovat jej lze v mnoha prostředích, včetně Arduino IDE, MicroPythonu, JavaScriptu (Moddable) nebo v nativním frameworku ESP-IDF.

Raspberry Pi

Raspberry Pi

Raspberry Pi je řada malých, cenově dostupných jednodeskových počítačů vyvinutých britskou nadací Raspberry Pi Foundation s cílem podpořit výuku informatiky ve školách. Na rozdíl od běžných mikrokontrolérů disponuje Raspberry Pi plnohodnotným procesorem architektury ARM, operační pamětí RAM a slotem pro microSD kartu, která slouží jako pevný disk pro operační systém (nejčastěji Raspberry Pi OS založený na Debianu). Počítač je vybaven USB porty, HDMI výstupem pro připojení monitoru, Ethernetem, Wi-Fi a Bluetooth konektivitou. Klíčovým prvkem pro kutily je 40pinový GPIO konektor, který umožňuje přímé ovládání elektronických součástek, jako jsou senzory, LED diody nebo motory. Díky své univerzálnosti se Raspberry Pi používá v široké škále projektů od domácích multimediálních center (Kodi), přes síťové blokovače reklam (Pi-hole), až po retro herní konzole nebo řídicí jednotky pro robotiku a průmyslovou automatizaci.
