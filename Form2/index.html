Rozcvička: Základní HTML značky

Úvod do HTML struktury

Tato úvodní stránka slouží jako cvičení pro rozpoznání základních HTML značek. Vaším úkolem je na základě vizuálního vzhledu odvodit použitý kod a strukturu.

Seznamy

Neuspořádaný Seznam (Značky)

  • Nadpisy (h1 - h6)
  • Odstavce (p)
  • Seznamy (ul, ol, li)
  • Tučný a zvýrazněný text (b, strong)

Uspořádaný seznam (Kroky)

  1. Analyzujte vizuální prvky.
  2. Indentifikujte HTML značky.
  3. Rekonstruujte kod.
